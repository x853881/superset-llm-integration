# AGENTS.md

Guidance for agents (and humans) working in this repository.

## Code comments

Don't add code comments for simple changes.

- If a change is small and its intent is clear from the code and the commit message, add no comment.
- Put the reason for a change in the commit message, not in a comment.
- Don't add or extend a doc comment just to describe a small tweak to a function, such as adding an attribute or a prop.
- Only comment when the code can't explain itself, for example a non-obvious constraint, a workaround or a surprising decision.
- Leave existing comments alone unless your change makes them wrong.
